Built for the data everything else depends on

Spreadsheets passed around by e-mail and ad-hoc SQL updates are how reference data usually changes. Lodestar gives those changes an owner, an approval and a history, without leaving Snowflake.

Easy for business users

Edit many rows at once in a familiar grid, paste rows copied from Excel, upload a CSV or Excel file, filter and export. No SQL needed.

Approval, effective dating and audit

Stewards propose, admins approve; self-approval is blocked by default. Every change has an effective date, a reason and a full history: query any point in time, revert in one click, see who changed what.

Data quality, watched for you

Check any column of your tables for values without a code or mapping, and why. Schedule the check daily or weekly, and the right people are emailed when new ones appear.

Code sets, mappings, hierarchies

Typed attributes validated on submit and on approval, crosswalks between systems with mapping suggestions (AI similarity with Snowflake Cortex if you turn it on), and parent/child trees.

Your own tables, governed where they live

Put existing control tables such as price lists and thresholds under governed editing. Approved inserts, updates and deletes are written to your table, with field-level history.

Use it everywhere

Always-current views for SQL, pipelines and BI, a semantic view for Cortex Analyst, a Cortex Agent in Snowflake CoWork and an MCP server for AI tools. Read-only, with each user's own access.

Questions

Does our data leave our Snowflake account?

No. Lodestar is a Snowflake Native App: your codes, tables and history stay in your account. Only error and warning logs reach us, so that we can detect and fix failures. The telemetry section lists exactly what they contain.

What does it cost to run?

Apart from the plan, the app uses Snowflake compute and storage in your account: one X-Small warehouse while someone is using the app, and a few MB of storage. Queries from your pipelines and BI run on your own warehouses. See Cost.

Who counts as an editor?

Anyone who proposed, approved, rejected, reverted or imported a change, or changed the app's set-up, in the last 30 days. People who only read the views or browse the app don't count. Going over doesn't block anyone; we'll talk to you about a larger plan.

Can we use the tables we already have?

Yes. Import from your own tables and views (or ones shared with you, such as Marketplace reference data), or register existing tables as managed tables and edit them where they are. See Working with your existing tables.

Does it work with AI assistants?

Yes. The app includes a Cortex Agent for Snowflake CoWork and an MCP server for Cortex Code, Claude, Cursor and other MCP clients. They are read-only and run with each user's own access. See AI agents and MCP.

What happens at the end of the trial?

Snowflake e-mails you before the trial ends. If you buy the plan, the same install continues with all your data; if not, the app is suspended and your data is kept as long as you don't uninstall it.
